# Governance

## Decision Model

This project is maintainer-led by [@shanewas](https://github.com/shanewas), who is the final decision-maker on merges and releases.

## Becoming a Maintainer

Contributors with a sustained record of quality pull requests may be invited to become maintainers. If you're interested, express it via a GitHub Discussion or issue.

## Release Process

Releases follow [Semantic Versioning](https://semver.org/). Changes are documented in [CHANGELOG.md](CHANGELOG.md), and releases are tagged on `master`.
