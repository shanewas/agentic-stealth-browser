You write a Playwright script, hit a protected site, and get blocked before your code even runs. Not because it's broken — because the site checked your TLS handshake, your WebGL renderer, your AudioContext, and whether `navigator.webdriver` still exists. Python's default TLS fingerprint gives it away every time.

I built an open-source library for this. Agentic Stealth Browser — still Python, still Playwright under the hood, but with a stealth layer that runs before the page loads:

- TLS fingerprints for specific regions (Japan, US, EU, Korea) instead of Python's defaults
- JS patches that strip automation flags before first paint
- Mouse movements and typing that don't look robotic
- Auto-recovery when a site still blocks you

Tested against bot.sannysoft.com, pixelscan.net, CreepJS — all pass in headless mode. v2.1.1 on PyPI, ~880 tests.

The tradeoff is real though: it's heavier than a plain Playwright script. More complexity, slower startup. Worth it if you need to reach anything behind Cloudflare or LinkedIn.
