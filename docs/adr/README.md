# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for the Agentic Stealth Browser project.

## What are ADRs?

ADRs document significant architectural decisions, their context, consequences, and trade-offs. They help future developers understand *why* the system is built the way it is.
