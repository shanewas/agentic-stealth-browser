# v2.4.0 Implementation Plan — Attach-Mode Hardening

> **For Hermes:** Use subagent-driven-development to execute this plan task-by-task.
> Two-stage review (spec compliance → code quality) per task.

**Goal:** Ship v2.4.0 as a tight attach-mode hardening release. Close the 4 open issues from PR #437's Clawpatch review (#438–#441), bump version, publish to PyPI.

**Architecture:** Reuse existing `is_url_safe()` helper (already does DNS resolution + `_BLOCKED_NETWORKS` checks) for the attach-mode loopback gate. **Tech Stack:** Python 3.10+, `ipaddress` stdlib, Playwright async API, `pytest-asyncio`. No new dependencies.

**Version:** `2.3.0` → `2.4.0` (minor bump — new loopback behavior + new return fields, backward compatible).

**Exit criterion:** `pytest` green, lint green, manual smoke (attach to local Chromium + a remote LAN browser), PyPI release live.

**Tasks:**

### Task 1.1: Add `fe80::/10` to `_BLOCKED_NETWORKS` + extract `is_loopback_or_blocked` helper
- Write failing test in `tests/test_mcp_url_safety.py` asserting `is_loopback_or_blocked("http://[fe80::1]:9222") is False` and `is_loopback_or_blocked("http://localhost:9222") is True`
- Run: `pytest tests/test_mcp_url_safety.py::test_link_local_blocked -v` — expect FAIL (function doesn't exist)
- Add to `production/mcp_server.py`:
  ```python
  _BLOCKED_NETWORKS = [
      ipaddress.ip_network("127.0.0.0/8"),
      ipaddress.ip_network("::1/128"),
      ipaddress.ip_network("0.0.0.0/8"),
      ipaddress.ip_network("10.0.0.0/8"),
      ipaddress.ip_network("172.16.0.0/12"),
      ipaddress.ip_network("192.168.0.0/16"),
      ipaddress.ip_network("169.254.0.0/16"),
      ipaddress.ip_network("fe80::/10"),  # NEW: link-local IPv6
  ]

  def is_loopback_or_blocked(url: str) -> bool:
      """Return True if url's host is loopback OR resolves to a blocked network.

      Use this for CDP attach gates where the operator might be on a remote
      host (WSL→Windows) but must never be on an attacker's network.
      """
      normalised = url.strip()
      if not normalised.startswith(("http://", "https://", "ws://", "wss://")):
          normalised = f"http://{normalised}"
      return is_url_safe(normalised)
  ```
- Run test — expect PASS
- Commit: `git commit -am "fix(mcp): add link-local IPv6 to blocked networks, expose is_loopback_or_blocked"`

## M3: Fix #439 — typed TeardownMode enum (30 min, ~30K tokens)

**Objective:** Replace the 3 separate `getattr` flag checks in `close()` with a single `TeardownMode` enum. Easier to reason about, easier to extend.

**Files:**
- Modify: `core/agent_browser.py` (add enum, replace 4 getattr sites)
- Test: `tests/test_attach_over_cdp.py` (add 1 unit test for the new state machine)

**Tasks:**

### Task 3.1: Define the enum and the state machine
- Write failing test:
  ```python
  def test_teardown_mode_enum_exists():
      from core.agent_browser import TeardownMode
      assert TeardownMode.LAUNCHED.value == "launched"
      assert TeardownMode.POOLED.value == "pooled"
      assert TeardownMode.ATTACHED_OWNED_CTX.value == "attached_owned_ctx"
      assert TeardownMode.ATTACHED_ADOPTED_CTX.value == "attached_adopted_ctx"
  ```
- Run — expect FAIL (enum doesn't exist)
- Add to `core/agent_browser.py` (top of file, after imports):
  ```python
  import enum

  class TeardownMode(enum.Enum):
      """State machine for how close() should release resources.

      Set by launch() / launch_pooled() / attach_over_cdp() / new_context=True
      branches. Read by close() exactly once.
      """
      LAUNCHED = "launched"  # Owns the browser process
      POOLED = "pooled"      # Borrowed a context from _BrowserPool
      ATTACHED_OWNED_CTX = "attached_owned_ctx"     # Attached + created new context
      ATTACHED_ADOPTED_CTX = "attached_adopted_ctx" # Attached + adopted user context
  ```
- Run test — expect PASS
- Commit: `git commit -am "refactor: add TeardownMode enum"`

### Task 3.2: Wire up the enum in launch paths
- In `core/agent_browser.py`:
  - `launch()` → set `self._teardown_mode = TeardownMode.LAUNCHED` (find the line where the browser is launched, ~line 134-160)
  - Pool acquire path → set `self._teardown_mode = TeardownMode.POOLED` (find where `_using_pool = True`, ~line 250)
  - `attach_over_cdp()`:
    - When `new_context=True` (or no existing contexts) → `self._teardown_mode = TeardownMode.ATTACHED_OWNED_CTX`
    - When adopting existing context → `self._teardown_mode = TeardownMode.ATTACHED_ADOPTED_CTX`
  - Init in `__init__`: `self._teardown_mode = None` (with a comment "set by launch/attach")
- Add failing test asserting `AgentBrowser()._teardown_mode is None` post-init
- Run — expect PASS
- Commit: `git commit -am "refactor: wire TeardownMode in launch/attach paths"`

### Task 3.3: Replace the getattr chain in `close()`
- In `core/agent_browser.py:2282-2309`, replace:
  ```python
  if self.browser:
      try:
          if getattr(self, "_attached", False):
              if getattr(self, "_attached_context_is_ours", False):
                  try: await self.browser.close()
                  except Exception: pass
              remote = getattr(self, "_remote_browser", None)
              if remote is not None:
                  try: await remote.close()
                  except Exception: pass
                  self._remote_browser = None
          elif getattr(self, "_using_pool", False) and getattr(self, "_pool", None):
              await self._pool.release_context(self.browser)
          else:
              await self.browser.close()
      except Exception: pass
      self.browser = None
  ```
  with:
  ```python
  if self.browser:
      try:
          mode = self._teardown_mode
          if mode == TeardownMode.ATTACHED_OWNED_CTX:
              try: await self.browser.close()
              except Exception: pass
              remote = self._remote_browser
              if remote is not None:
                  try: await remote.close()
                  except Exception: pass
                  self._remote_browser = None
          elif mode == TeardownMode.ATTACHED_ADOPTED_CTX:
              remote = self._remote_browser
              if remote is not None:
                  try: await remote.close()
                  except Exception: pass
                  self._remote_browser = None
          elif mode == TeardownMode.POOLED and getattr(self, "_pool", None):
              await self._pool.release_context(self.browser)
          elif mode == TeardownMode.LAUNCHED:
              await self.browser.close()
          # mode is None → browser was never set up; no-op
      except Exception: pass
      self.browser = None
  ```
- Run all `tests/test_attach_over_cdp.py` — expect 7/7 PASS (close-after-attach and re-attach round-trip must still work)
- Run full unit suite: `python3 -m pytest -m "not e2e" -q` — expect 893+ pass, 0 fail
